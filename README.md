# Dieta

App personale (PWA) per seguire il piano alimentare, preparare la spesa e tenere la dispensa.

- Aprila in Safari su iPhone → Condividi → **Aggiungi a Home**.
- I dati (dispensa, spese, sostituzioni) restano solo sul telefono: usa *Impostazioni → Esporta* per il backup.
- Test del motore: `npm test`
